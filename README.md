# 🐸 Toán 2 Phiêu Lưu Ký

Ứng dụng học tập Toán lớp 2 vui nhộn, siêu trực quan dành cho các bé 7 tuổi học tập theo chương trình sách giáo khoa **Kết nối tri thức với cuộc sống (Tập 1)**.

## ✨ Các tính năng chính:
- **36 bài học bám sát sách giáo khoa**: Đầy đủ 36 bài học được phân bổ thành 7 chủ đề lý thuyết toán học lớp 2.
- **Lý thuyết trực quan & sinh động**: Cách giải thích khái niệm toán học bằng ngôn ngữ gần gũi với trẻ nhỏ, kèm ảnh sơ đồ minh họa kích thước lớn.
- **Thực hành tương tác**: Nhúng các phòng thí nghiệm toán học tương tác (tia số, khối chục/đơn vị, khung 10 ô, cân đĩa ki-lô-gam, bình đo lít, xem đồng hồ kim...).
- **720 Câu hỏi và Bài tập tự luận**: Giao diện điền câu trả lời thông minh với phông chữ lớn, hỗ trợ tự động **Lưu tạm bản nháp** trực tuyến.
- **Đồng bộ đám mây GitHub & Email cho Bố Mẹ**:
  - Không lưu trữ bất kỳ dữ liệu cá nhân nào cục bộ trên thiết bị của bé.
  - Khi hoàn thành bài học, bài làm sẽ tự động được gửi qua email cho Bố Mẹ để tự chấm điểm, đồng thời lưu trữ tiến trình học tập lên kho chứa GitHub.

## 🚀 Cách khởi động cục bộ:
1. Cài đặt các gói phụ thuộc:
   ```bash
   npm install
   ```
2. Khởi chạy máy chủ phát triển (Dev Server):
   ```bash
   npm run dev
   ```
3. Truy cập địa chỉ hiển thị trong terminal (mặc định: `http://localhost:5173`).
